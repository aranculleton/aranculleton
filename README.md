# Aran Culleton

I'm a Data Science Consultant at Xantura (Newton Europe), previously at British Airways and the BBC.
I work across applied machine learning, analytics engineering, forecasting and risk decisioning.

Most of my work sits where data science meets operations: SQL and Python pipelines,
model-ready datasets, validation checks, scoring systems, and dashboards people actually use.
Recent work includes prioritization models over 1.5M+ sensitive records, and ingestion and QA
workflows that cut data-prep cycles from weeks to days.

## Projects

- **[last-job-search](https://github.com/aranculleton/last-job-search)**: an open-source system
  that runs a job search end to end with Claude. It screens and scores thousands of postings,
  drafts and verifies tailored applications, and tracks every follow-up, with 900+ tests behind
  it. It never sends anything itself; a person does.
- **[openroles](https://github.com/aranculleton/openroles)**: a small, dependency-free Python
  library and MCP server that reads open roles straight from employers' Greenhouse, Lever,
  Ashby and Workday boards.
- **[CaseSignal](https://github.com/aranculleton/casesignal)**: a credit-risk decisioning
  prototype on synthetic data, inspired by my work at Xantura (Newton Europe). It ranks
  high-risk cases and explains what moved them.
- **[CopulAX](https://github.com/aranculleton/copulax)**: I made a small contribution to this
  JAX-based copula modelling library.
